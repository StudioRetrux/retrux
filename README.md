# Retrux Hero R&D

Everything needed to continue the real-time Retrux ice hero (three.js) on another machine:
the site code, the Blender / validation pipeline, the environment bakes, the reference
videos and the R&D notes. Private repo.

## Layout

| folder | what |
|---|---|
| `retrux-web/` | The Next.js site + the hero engine (`app/hero/engine/`, vanilla three.js r184). Architecture: `retrux-web/app/hero/README.md`. Lab server: `hero-lab/serve.mjs` |
| `hero-pipeline/` | Blender bake scripts, headless-Chrome validators, reference frames, research notes (`hero-pipeline/README.md`) |
| `pipeline/` | The working R&D scripts from the Nov 2026 sessions: probes (`probe_*.mjs`), QC judges (`judge_round*.js`), Blender preps / renders (`prep_v*.py`, `render_plates_v*.py`, `render_v*_all.ps1`, `finalize_*.ps1`), ring mocap fit (`ringfit/`), RAM watchdog (`tools/watchdog.ps1`) |
| `blender/plate_scene_v7.blend` | The latest self-built environment scene (v7: centroid massif split, lowered far-left ridge). Textures are packed, so the "missing" external paths do not matter |
| `blender/plates_v7/` | The v7 plate renders (EXR + camera JSON) for the rest, tilt, hold, orbN and orbP projectors |
| `blender/bake_v8/` | The latest baked environment GLB + per-batch JSON and the baked textures |

## Setup on a new laptop

1. Install Git, Node 24 (v24.14.1 was used) and Blender 5.2 (only for environment re-bakes).
2. Clone and install:
   ```powershell
   gh auth login --web       # or sign in when git asks
   git clone https://github.com/fvldi/retrux-hero-rnd.git
   cd retrux-hero-rnd\retrux-web
   npm ci
   npm run hero:lab          # lab on http://localhost:5173 (also on the LAN)
   npm run dev               # or the full Next.js page
   ```
   Lab flags: `?debug=1`, `?tier=T0..T3`, `?scale=0.6`, `?proj=0`, `?ibi=0/1`.
   `window.__hero.debug.pose/settle/freeze` give deterministic frames.
3. Validators / probes need Playwright + ffmpeg:
   ```powershell
   cd ..\hero-pipeline\tools
   npm ci
   ```
4. Vercel WIP deploys (https://retrux-hero-wip.vercel.app): the `.vercel` link and
   `.env.local` are not in the repo. Run `npx vercel@latest link` in `retrux-web`, choose
   the existing project `retrux-hero-wip`, then `npx vercel@latest deploy --prod --yes`.
5. Claude Code memory: copy `notes/claude-memory/*.md` into
   `%USERPROFILE%\.claude\projects\<project-slug>\memory\` on the new laptop, so Claude knows
   the project history. The slug is the clone path with `:` `\` and spaces turned into `-`
   (e.g. `C:\dev\retrux-hero-rnd` -> `C--dev-retrux-hero-rnd`).

## Laptop notes

On an 8 GB laptop run one heavy job at a time (Blender, Chrome captures, `next build`,
big Python jobs), and start `pipeline/tools/watchdog.ps1` first. Blender: Cycles only,
3 threads, render in strips, never save over the source `.blend`.
